# 本周课表工具

一个纯命令行的大学课表查看工具：支持手动录入、CSV 导入、教务系统 xlsx 课表导入（按周次筛选），以「时间 × 星期」网格打印本周课表，并可导出为带样式的 Excel 文件。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `schedule.py` | 基础版：录入 / CSV 导入 / xlsx 导入 / 打印课表 / 导出 Excel |
| `schedule2.py` | 增强版：在基础版之上增加「每天空闲时段查询」，并自动合并同课程连堂小节（同一天间隔 ≤ 15 分钟的相邻小节合并为一个时段） |

## 功能特性

- **三种课程来源**
  - 交互式手动录入（课程名留空结束）
  - CSV 文件导入（自动跳过表头和坏行）
  - 教务系统导出的 xlsx 课表导入，按**周次**筛选（如「1-4周,6-18周」），自动解析教师与教室
- **文本课表视图**：按 时间 × 星期 打印对齐网格（中文全角按 2 列宽计算）
- **导出 Excel**：生成带表头样式、边框、自适应列宽的 `.xlsx`，含「课程详情」工作表（教师 / 地点）
- **空闲时段查询**（`schedule2.py`）：指定每日可用范围（默认 08:00-22:00），扣除课程后列出每天可用的空闲时间段

## 环境要求

- Python 3.7+
- `openpyxl`（仅 xlsx 导入 / 导出功能需要）

```bash
pip install openpyxl
```

## 用法

### 交互菜单

```bash
python schedule2.py
```

### 命令行直连

```bash
python schedule2.py courses.csv              # 导入 CSV 并打印
python schedule2.py courses.csv 输出.xlsx     # 导入 CSV、打印并导出 Excel
python schedule2.py 课表.xlsx                # 按今天推算的周次导入 xlsx 并打印
python schedule2.py 课表.xlsx 3              # 指定导入第 3 周
python schedule2.py 课表.xlsx 3 输出.xlsx     # 指定周次并导出 Excel
```

### CSV 格式（含表头）

```csv
课程名,星期几,开始时间,结束时间
高等数学,周一,08:00,09:40
大学英语,3,14:00,15:40
```

- 星期几支持：`周一`~`周日`、`星期一`~`星期日`、`1`~`7`、`天`/`日` 均可
- 时间格式：`HH:MM`（如 `08:00`）

### xlsx 课表格式（教务系统导出）

表头行需包含 `星期一`~`星期日` 共 7 列，课程单元格格式：

```
课程名 课程号
1-4周,6-18周 教师姓名 08:00-09:40 【教学楼 301】
```

### 学期周次

`schedule2.py` 第 20 行的 `SEMESTER_START` 为本学期第 1 周的周一日期，请按自己学校的校历修改：

```python
SEMESTER_START = datetime.date(2026, 8, 31)
```
